# T009 evidence: vehicle model kit

- `triangle_counts.md`: per-part LOD0/LOD1/phone triangle counts and file sizes (97 parts, all within budget).
- `assembly_joints.md`: measured mating-ring gaps for the three assembled vehicles (all pass, < 2 mm).
- `beauty_*.png`: one beauty render per vehicle (full and engine close-up) plus `beauty_lineup_all_vehicles.png`.
- `contact_sheet_*.png`: contact sheets of every part family (engines S1/S2, mounts S1/S2, tanks, adapters, fairings, interstages, boosters).
- Part-ID mapping: `assets/blender/data_part_map.json` maps each `data/parts` ID (7.5-7.9, 7.11, 7.12) to kit meshes.

Not modelled: `strap_2_liquid_side` (design 7.11) has no dedicated mesh; T006/T009 scope was the two solid boosters.
