AI-assistance disclosure

The code of this project was written with AI coding agents under human direction. Agents from OpenAI (Codex) and Anthropic (Claude Code) wrote and tested code, data files, documents and tooling in separate branches; the team owner assigned the tasks, reviewed and merged the results. Every task, its brief and its verification evidence are kept in orchestration/ in the repository.

WhatMade withNotes
Game code (C# core, Unity host, Node room server, TypeScript phone client)AI coding agents (Codex, Claude Code)Tests accompany the code; simulation is deterministic from a seed.
Game text, data tables, codex and factsAI coding agents, then a fact-verification passEach fact carries a source URL; see Data sources below.
Images (title, build bay, ascent, orbit, re-entry, mission control, two key-art frames)Higgsfield generate_image with model gpt_image_2_68 approved stills, 10 Higgsfield credits spent in total; no text, logos or watermarks by inspection.
Briefing video (10 s, C1 Earth Watch)Google Gemini video export supplied by the project owner; exact model and prompt not providedAudio removed with a lossless FFmpeg remux. Not re-encoded.
AudioNone bundledNo audio recordings are in the repository at the time of writing; the host only has audio hooks.
3D modelsBlender scripts (assets/blender/scripts/) written by AI coding agents; FBX and GLB exportsGeneric hardware, not copies of real spacecraft. Source .blend files are in assets/blender/.
